# Maps-for-Simulating-a-LiDAR-Based-Mobile-Robot
Custom 3D simulation arenas (map1, map2, map6) designed in Autodesk Fusion for testing mobile robot navigation, SLAM, obstacle avoidance, and LiDAR raycasting across orthogonal, angled, and curved obstacle geometries. Credits: Rakshith S Kumar &amp; Anirudh Shridhar.
